# midi-keyboard

  <img width="1629" height="978" alt="3d-midi-1" src="https://github.com/user-attachments/assets/35036788-f84c-4991-92d1-85a9a72b54ce" />


  ** ↑↑A midi keyboard with a hexagonal theme based off of [hack club half-life's week 3 guide](https://github.com/KaiPereira/MIDI-Keypad/blob/master/README.md) ↑↑ ** 

  ## Features and components:
  - Hex shaped copper  capactive touch pads that act like keys
  - A spinning rotary encoder that controls volume
  - 2 bourns sliding potentiometers that can control expression and modulation
  - 3 customizable keys for stuff
  - designs made by me
